🏆 成就配置（随右上角「保存全部」一并保存）
说明：每条成就 = 编号 no（永不变，只增不复用） + key（稳定 id） + 文案 + 稀有度 + 解锁条件。
① key 只读——它是解锁记录在浏览器本地存储里的主键，改了 = 所有人的解锁记录作废（成就全变回未解锁），而且不报错。
② 名字与描述是纯文本（游戏里会转义），别写 HTML 标签；描述可用占位符：{model} 模型名 · {param} 参数档 · {arch} 架构名。
③ 条件按白名单自动生成；「全部满足 / 任意一条」可以嵌套子条件。条件里不要写死条数（「全部论文」「全架构」由引擎按真源现取）。
④ 稀有度同时驱动卡面配色、发光、环层数、粒子数与默认图标（颜色在 h5_demo/style.css 的 .rarity-* 里改）。
